## Usage Instructions

1. Copy this template for each policy selected in Phase 3
2. Save as `phase3/policy_[ID]_initial_paper.md`
3. Fill in all sections
4. Flag any unverified sources
5. Submit for QA review

## Quality Checklist

- [ ] All 9 sections completed
- [ ] Summary is 2-3 sentences
- [ ] At least 3 pros and 3 cons listed
- [ ] Cost estimates include confidence levels
- [ ] Political considerations assessed
- [ ] All sources cited and flagged for verification
- [ ] Recommended pathway clearly identified
- [ ] Total length approximately 2 pages
