# Phase 3: Policy Refinement - Workflow

## Overview

Phase 3 takes policies selected by the Human Principal and develops them into comprehensive, implementation-ready recommendations. This phase involves deep research, economic analysis, feasibility assessment, political strategy, legislative drafting, and communications development.

**Note:** This is a shared workflow used by all projects. File paths like `outputs/phase3/` refer to the current project's folder.

---

## Phase Objectives

1. Conduct deep research on selected policies
2. Develop comprehensive analysis for each policy
3. Create implementation roadmaps
4. Draft legislative language where applicable
5. Develop communications materials
6. Produce final policy recommendation papers

---

## Inputs Required

From Human Principal:
- List of policies selected for refinement
- Priority ranking of selected policies
- Any specific questions or concerns to address
- Timeline expectations

## Step-by-Step Instructions

### Step 1: Assignment (Council Director)

**Actions:**
1. Review policies selected by Human Principal
2. Prioritize based on Human Principal direction
3. Assign research tasks to Research Librarian
4. Brief all agents on their roles
5. Establish timeline and milestones

**Assignment Matrix:**
| Policy | Research Librarian | Economist | Implementation | Political | Legislative |
|--------|-------------------|-----------|----------------|-----------|-------------|
| [Policy 1] | ✓ | ✓ | ✓ | ✓ | If applicable |
| [Policy 2] | ✓ | ✓ | ✓ | ✓ | If applicable |

---

### Step 2: Deep Research (Research Librarian)

**Deliverable:** Research Briefing for each policy

**Research Agenda:**
1. **Academic Literature**
   - Relevant peer-reviewed research
   - Working papers from major institutions
   - Meta-analyses if available

2. **Expert Identification**
   - Leading academics on the topic
   - Think tank experts (noting perspectives)
   - Practitioners with relevant experience
   - Government officials with expertise

3. **Precedent Analysis**
   - Similar policies attempted in US
   - State-level experiments
   - International examples
   - Historical precedents

4. **Stakeholder Mapping**
   - Who would support this policy?
   - Who would oppose?
   - Key influencers
   - Affected communities

5. **Evidence Assessment**
   - What do we know with confidence?
   - What is uncertain?
   - What are the research gaps?

---

### Step 3: Parallel Analysis

#### Economist Analysis
**Deliverable:** Economic Analysis Report

Components:
- Cost estimation (government, compliance, opportunity)
- Benefit quantification (where possible)
- Distributional analysis
- Goal alignment assessment
- Economic impact modeling
- Sensitivity analysis

#### Implementation Specialist Analysis
**Deliverable:** Feasibility Assessment and Implementation Plan

Components:
- Feasibility rating (High/Medium/Low)
- Agency capacity assessment
- Resource requirements
- Phased implementation roadmap
- Key milestones
- Risk identification and mitigation

#### Political Strategist Analysis
**Deliverable:** Political Viability Assessment

Components:
- Congressional support assessment
- Coalition mapping
- Timing considerations
- Strategic positioning recommendations
- Pathway options (legislation, regulation, executive)
- Potential amendments for broader support

---

### Step 4: Legislative Development (SA-01: Legislative Counsel)

**When Applicable:** Policies that would require legislation

**Deliverable:** Draft Legislative Concept

Components:
- Bill structure and sections
- Key statutory language
- Definitions
- Enforcement provisions
- Implementation timeline
- Regulatory authority
- Appropriations (if needed)

**Note:** Include disclaimer that formal drafting requires Legislative Counsel.

---

### Step 5: Analyst Review

**Memory-Informed Review Process:**

Before reviewing, each analyst should:
- Review their Phase 1 memory (what ideas they proposed, what themes they emphasized)
- Review their Phase 2 memory (how they voted on this policy, what concerns they raised)
- Note their recorded positions and commitments from earlier phases

**All 16 Analysts Review:**
1. Read refined policy analysis
2. Provide written feedback from their perspective
3. **Reference earlier positions:** "In Phase 2, I voted YES because... This refined version addresses my concern about..."
4. Flag any concerns or objections
5. Suggest final modifications
6. Indicate level of support (Strong Support / Support / Neutral / Oppose)
7. **Record in memory:** Add review to `phases.phase3.policies_refined` or `detailed_analyses_provided`

**Deliverable:** Analyst Review Summary
- Support distribution across perspectives
- Key concerns raised (especially those carried forward from Phase 2)
- Suggested modifications
- Final coalition assessment
- Consistency check: Do analysts maintain positions from Phase 2?

#### Communications Lead
**Deliverables:**
- One-pager summary
- Talking points
- FAQ document
- Press-ready summary

#### Designer
**Deliverables:**
- Policy overview graphic
- Cost-benefit visualization
- Implementation timeline
- Key statistics graphics

---

### Step 7: QA and Final Review

**QA/Fact Checker:**
- Verify all factual claims
- Check statistics and sources
- Confirm accuracy of citations
- Validate cost estimates methodology

**Council Director:**
- Review all documents for quality
- Ensure completeness
- Verify consistency across materials
- Approve for Human Principal presentation

---

### Step 8: Human Principal Presentation

**Final Deliverables Package:**

1. **Policy Recommendation Papers** (one per goal or major policy)
   - Full analysis documents
   - Executive summaries

2. **Legislative Concepts** (where applicable)
   - Draft bill language
   - Implementation provisions

3. **Communications Package**
   - One-pagers
   - Talking points
   - FAQs

4. **Visual Materials**
   - Key graphics and charts
   - Presentation slides

5. **Supporting Documentation**
   - Full research briefs
   - Economic analysis details
   - Implementation plans
   - Political assessments

## Quality Standards

### Recommendation Papers Must Include
- [ ] Clear executive summary
- [ ] Comprehensive problem statement
- [ ] Detailed solution description
- [ ] Evidence base with citations
- [ ] Economic analysis summary
- [ ] Implementation roadmap
- [ ] Political viability assessment
- [ ] Stakeholder analysis
- [ ] Clear recommendation
- [ ] All claims fact-checked

### Legislative Drafts Must Include
- [ ] Proper bill structure
- [ ] Clear definitions
- [ ] Enforceable provisions
- [ ] Implementation timeline
- [ ] Disclaimer about formal drafting

- Additional research on specific aspects
- Alternative approaches explored
- Modifications to recommendations
- Additional policies added

Phase 3 may cycle multiple times as policies are refined based on feedback.
