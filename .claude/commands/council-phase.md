# Run Specific Policy Council Phase

Run a specific phase of the policy council workflow.

## Usage
/council-phase <phase_number> [--project <name>]

## Instructions for Claude

Phases:
- 1: Ideation (spawn analysts to generate ideas)
- 2: Voting (run all 6 vote types)
- 3: Refinement (create 2-page papers)
- 4: Development (deep research, 23-section papers)
- 5: Rollout (generate 15 deliverables)

Follow phase-specific workflow from `shared/workflows/phase{N}_*.md`
