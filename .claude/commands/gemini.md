# Generate with Gemini

> **Integration:** This command uses the optional Gemini integration. See `shared/integrations/gemini/` for configuration.

Generate expanded legislative approaches using Gemini API via Cloudflare Worker.

## Arguments
- `$ARGUMENTS` - Prohibition name (e.g., `automated-firing`) or `all` for all prohibitions

## Instructions

You are generating Gemini-powered legislative approaches. Your task is to call the Gemini API worker and save the output.

### Configuration

**Worker URL**: `https://gemini-prohibitions.adamconner7.workers.dev`

**Available Prohibitions** (use exact names):
- Labor: `automated-firing`, `ai-task-management`, `individualized-wages`, `surveillance-pricing`, `rent-collusion`
- Government: `critical-infrastructure`, `tracking-social-scoring`, `autonomous-judicial`, `unlabeled-ai-content`, `government-data-training`
- Civil Rights: `emotion-recognition`, `predictive-policing`, `election-deepfakes`
- Healthcare: `ai-insurance-claim-denial`, `autonomous-medical-decisions`, `patient-financial-predictions`, `variable-healthcare-pricing`, `patient-data-reidentification`
- Education: `ai-custodial-care`, `automated-discipline-decisions`, `opaque-admissions-algorithms`

### Execution Steps

1. **Parse Arguments**: Determine if generating for one prohibition or all.

2. **Load Prohibition Description**: Read from `projects/ai-prohibitions-draft-legislation/gemini-integration/scripts/generate_approaches.py` to get the list of prohibition names and descriptions.

3. **Build Prompt**: Use this template:
   ```
   You are a legislative policy expert. Generate 10 federal and 10 state legislative approaches for the following AI prohibition:

   **Prohibition:** [DESCRIPTION]

   For each approach, write a single paragraph (3-5 sentences) describing:
   - The legislative mechanism (statute, regulation, amendment, etc.)
   - Key provisions
   - Enforcement mechanism
   - Unique value of this approach

   Format as:
   ## Federal Approaches
   ### 1. [Approach Name]
   [Paragraph]
   ... (10 total)

   ## State Approaches
   ### 1. [Approach Name]
   [Paragraph]
   ... (10 total)
   ```

4. **Call the Worker**: Use the `read_url_content` tool or make an HTTP POST request:
   ```
   POST https://gemini-prohibitions.adamconner7.workers.dev
   Content-Type: application/json

   {
     "prompt": "[YOUR PROMPT]",
     "prohibition": "[PROHIBITION_NAME]",
     "outputType": "expanded_approaches"
   }
   ```

5. **Save Output**: Write the response content to:
   `projects/ai-prohibitions-draft-legislation/outputs/[prohibition-name]/expanded_approaches_gemini.md`

   Include header:
   ```markdown
   # Expanded Legislative Approaches: [Title]

   > **Generated by:** Google Gemini
   > **Date:** [YYYY-MM-DD]

   ---

   [CONTENT FROM API]

   ---

   *Generated by Gemini | AI Policy Council Legislative Drafting Project*
   ```

6. **Rate Limiting**: If generating `all`, wait 2 seconds between calls to avoid rate limits.

### Example

For `/gemini automated-firing`:
- Output file: `projects/ai-prohibitions-draft-legislation/outputs/automated-firing/expanded_approaches_gemini.md`
